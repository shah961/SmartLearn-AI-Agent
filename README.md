SmartLearn AI Agent 🚀

SmartLearn AI Agent is an AI-powered study assistant built for the Google Cloud Rapid Agent Hackathon.

The project helps students learn topics faster using Gemini AI and Elastic search capabilities. Users can enter any study topic and receive:

- Simplified explanations
- Key notes
- Quiz questions
- Study plans

Features

- AI-powered responses using Gemini
- Search-enhanced learning
- Interactive study support
- Clean and simple interface
- Flask backend

Tech Stack

- Python
- Flask
- Gemini AI API
- Elastic Search
- Replit

Goal

To create a smart AI learning agent that makes studying easier, faster, and more interactive for students.

Status

Currently in active development for the hackathon.
