# 🎓 SmartLearn AI

> Learn Faster. Remember Longer. Study Smarter.

SmartLearn AI is an AI-powered personalized learning assistant that generates lessons, quizzes, flashcards, revision notes, summaries, and personalized study coaching using Google Gemini AI.

---

# 🚀 Features

## 📚 AI-Powered Lessons
Generate easy-to-understand lessons for any topic.

## 🧠 Key Concepts
Extract important concepts automatically.

## 🗺️ Learning Roadmap
Get a structured learning path.

## ❓ Quiz Generation
Practice with AI-generated questions.

## ⏱️ 30-Minute Study Plan
Focused learning sessions.

## 🔍 Knowledge Gap Analysis
Identify weak areas.

## 💡 Study Tips
Personalized recommendations.

## 🎯 Study Coach

Generate:

- Today's Focus
- Tomorrow's Focus
- Weekly Plan
- Revision Strategy
- Estimated Mastery Time
- Personalized Recommendations

## 🃏 Interactive Flashcards

- Active Recall Learning
- Tap To Flip Cards
- Mobile Optimized

## 📝 Revision Notes

Quick revision material.

## 📄 Summary Generation

Condensed topic summaries.

## 📱 Mobile Friendly

Optimized for smartphones and tablets.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/shah961/SmartLearn-AI.git

cd SmartLearn-AI
```

## Install Dependencies

```bash
pip install -r requirements.txt
```


## Run Locally

```bash
python app.py
```

Open:

```text
https://smart-learn-ai-agent.vercel.app
```

# 🎯 How It Works

1. Enter a Topic
2. Select Subject
3. Select Difficulty
4. Select Learning Goal
5. Generate Personalized Learning Content

SmartLearn AI creates:

- Explanation
- Key Points
- Learning Roadmap
- Quiz
- Study Plan
- Knowledge Gap Analysis
- Study Tips
- Study Coach
- Flashcards
- Revision Notes
- Summary
